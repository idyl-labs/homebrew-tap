# Idyl Homebrew Tap

```bash
brew tap idyl-labs/tap
brew install --cask idyl-labs/tap/idyl
```

The currently published cask installs the `idyl` workstation CLI. It does not
create node identity, join a Fleet or Subnet, install a production Linux Node,
or own `/opt/idyl`. Production Node installation uses the separately verified
bootstrap installer.

`Casks/idyl.rb` is generated by the `cli` release workflow; its artifact stanzas
are the exact contract for the binaries in that release. A coordinated
workstation release may include the compatible `idyld` companion, but the cask
must never install or update the production Node systemd lifecycle.

To remove generated local service integration while preserving node identity,
run:

```bash
idyl node uninstall-service
```
