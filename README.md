# Idyl Homebrew Tap

```bash
brew tap idyl-labs/tap
brew install --cask idyl-labs/tap/idyl
```

The cask installs the `idyl` CLI and the compatible `idyld` companion binary
from one coordinated macOS release archive. It does not create node identity,
join a fleet or subnet, install a LaunchAgent, or start `idyld`.

`Casks/idyl.rb` is generated by the `cli` release workflow so its version,
checksums, binaries, and uninstall stanza stay tied to the published combined
artifact.

To remove generated local service integration while preserving node identity,
run:

```bash
idyl node uninstall-service
```
